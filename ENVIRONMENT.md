# Project Environment Context

This file defines the target environment for this repository. All code generation, scripts, and LuCI development configurations generated by AI must comply with these specifications.

## Target System & Architecture
* **OS**: OpenWrt 25.12.4 (Branch: `openwrt-25.12`, Revision: `r32933-4ccb782af7`)
* **Environment**: Virtual Machine (Testing Environment)
* **Architecture**: `x86_64` (Intel/AMD 64-bit)
* **Linux Kernel**: `6.12.87` (Kernel modules path specific to this build)

## Development Target
* **Primary Target**: LuCI Web Interface applications (openwrt-25.12 branch compatible).
* **LuCI Stack**: Modern client-side JavaScript LuCI API (`XHR`, `luci.js`, `rpc.js`) matching the 25.12 release standards.

## Package Management & File Paths (Critical Changes)
The system uses `apk` (Alpine Package Keeper). Do NOT use `opkg` or legacy opkg paths.

* **Package Manager**: `apk`
* **Package Index Format**: `.adb` (e.g., `packages.adb`)
* **Feed Configurations**: `/etc/apk/repositories.d/distfeeds.list`
* **Package Database Directory**: `/lib/apk/db/`
* **Installed Packages Log**: `/lib/apk/db/installed`
* **Package Triggers**: `/lib/apk/db/triggers`

## Key Feed URLs (for reference and dependency resolution)
* Base System: `https://downloads.openwrt.org/releases/25.12.4/packages/x86_64/base/`
* LuCI Apps: `https://downloads.openwrt.org/releases/25.12.4/packages/x86_64/luci/`
* General Packages: `https://downloads.openwrt.org/releases/25.12.4/packages/x86_64/packages/`
* Kernel Modules (`kmods`): `https://downloads.openwrt.org/releases/25.12.4/targets/x86/64/kmods/6.12.87-1-d037e17efc2c7cd4972f63d6de88677f/`

## Constraints for AI Developer
1. **No Opkg**: Never generate setup scripts using `opkg update` or `opkg install`. Use `apk update` and `apk add`.
2. **LuCI Compatibility**: Ensure all generated LuCI controllers and views comply with the JS-based LuCI framework used in OpenWrt 25.12.
3. **Paths Check**: Always look up package statuses in `/lib/apk/db/installed` instead of `/usr/lib/opkg/info/`.
