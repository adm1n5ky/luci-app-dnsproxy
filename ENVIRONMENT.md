# Project Environment Context

This file defines the target environment for this repository. All code generation, scripts, and commands generated by AI must comply with these specifications.

## Target Operating System
* **OS**: OpenWrt
* **Release**: 25.12.4
* **Branch**: openwrt-25.12
* **Revision**: r32933-4ccb782af7
* **Web UI**: LuCI (openwrt-25.12 branch)

## Package Management
* **Package Manager**: `apk` (Alpine Package Keeper)
* **Constraint**: Do NOT use `opkg`. All package operations must use `apk` syntax.
* **Common Commands**: 
  * Update feeds: `apk update`
  * Install package: `apk add <package>`
  * Search package: `apk search <package>`

## Architecture & Shell Constraints
* **Default Shell**: Ash (BusyBox)
* **Script Shebang**: `#!/bin/sh`
* **Constraint**: Avoid Bash-isms unless Bash is explicitly installed. Keep scripts lightweight and compliant with POSIX/Ash.

## Development Guidelines for AI
1. When creating network configurations, strictly use the OpenWrt Unified Configuration Interface (UCI) or edit `/etc/config/` files directly.
2. Ensure firewall rules are compatible with `fw4` (Nftables), which is default for this OpenWrt version.
